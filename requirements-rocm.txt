# AMD ROCm Requirements for manga-image-translator
# For AMD GPUs with ROCm support (e.g., RX 7700 XT, RX 7900 XTX, RX 6800 XT, etc.)
#
# Installation Steps:
# ==================
#   1. First install PyTorch with ROCm support:
#      pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm6.2
#
#   2. Then install this requirements file:
#      pip install -r requirements-rocm.txt
#
# Environment Variables:
# =====================
# Your GPU architecture affects HSA_OVERRIDE_GFX_VERSION environment variable:
#   - RX 7700 XT / 7800 XT (gfx1101): export HSA_OVERRIDE_GFX_VERSION=11.0.0
#   - RX 7900 XTX / 7900 XT (gfx1100): export HSA_OVERRIDE_GFX_VERSION=11.0.0
#   - RX 6800 / 6800 XT / 6900 XT (gfx1030): export HSA_OVERRIDE_GFX_VERSION=10.3.0
#
# CTranslate2 Note:
# ================
# CTranslate2 ROCm support requires building from source or using the forked version:
#   https://github.com/sssshhhhhh/CTranslate2
# The standard ctranslate2 package will use CPU only for translation.
# Other operations (OCR, detection, inpainting) will still use GPU via PyTorch ROCm.
